# AIML Practicals

This repository contains 9 practical assignments based on Artificial Intelligence and Machine Learning concepts.

## 📚 Practicals Included

| No. | Practical | Algorithm / Concept |
|---|---|---|
| 1 | Association Analysis | Correlation |
| 2 | Clustering | K-Means Clustering |
| 3 | Dimensionality Reduction | PCA |
| 4 | Classification | Naive Bayes |
| 5 | Classification | K-Nearest Neighbors (KNN) |
| 6 | Regression | Linear Regression |
| 7 | Regression | Support Vector Regression (SVR) |
| 8 | Regularization | Ridge and Lasso |
| 9 | Object Detection | YOLO + OpenCV Webcam |

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- OpenCV
- Ultralytics YOLO
